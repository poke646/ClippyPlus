# ClippyPlus

ClippyPlus is a lightweight tray application for Windows and macOS that combines fast screenshots, instant editing of the last capture, and private clipboard history in one focused tool. It is built to make everyday work with screen snippets and copied content faster, more predictable, and less scattered than using separate system utilities.

## What It Does

- captures screenshots with a global keyboard shortcut (bindable to your preference),
- lets you immediately edit the last screenshot or any previous screenshot from the clipboard history,
- stores clipboard history locally,
- can encrypt clipboard history with a password,
- hides its own clipboard history windows from screenshots and screen sharing,

## Why It Is Useful

The standard Snipping Tool on Windows and the built-in screenshot tools on macOS are good for single captures, but they do not naturally connect screenshots, quick editing, and clipboard history. System clipboard history focuses on copied items, but it does not offer the same privacy controls, clipboard diagnostics, or screenshot-oriented workflow.

ClippyPlus brings these needs into one simple workflow: capture part of the screen, return to the last screenshot, find previously copied content, and do it all from one place. It is especially useful for technical work, documentation, customer support, testing, bug reports, and any task where screenshots and clipboard items are used many times a day.

## Why It Is Better Than System Tools

- one global set of shortcuts instead of switching between separate system features,
- screenshots, quick editing, and clipboard history in a single workflow,
- local clipboard history with password protection,
- privacy option to hide clipboard history from accidental screenshots or screen sharing,
- diagnostic tools that help identify which application is currently blocking the clipboard (on Windows)
